# knoiren-browser
A singlefile node proxy + browser with extreme compatibility that is almost equal to scramjet / ultraviolet level proxies.
On certain tests it can even outperform Scramjet.

## How to run

Must have Node js 20.19+ installed

```bash
curl -sL https://cdn.jsdelivr.net/gh/ltorl/knoiren-browser/index.js | node
```
